# Audio

ElevenLabs sound effects and music for Cupcake Cannibal.

- `sfx/` — original ElevenLabs MP3s, named by game cue (see `prompt.md` cue list).
- `voice/` — narrator lines (`countdown_321_cupcake`: "3, 2, 1, cupcake!").
- `music/` — background loops (`cupcake_brawl`, `cupcake_clash_loop`).
- `wav/` — 44.1 kHz 16-bit WAV conversions of every MP3, for importing into Unreal (UE imports WAV, not MP3).

Missing from the cue list: `bite_hit`, `cane_windup`, `sun_melt`. `unlabeled_sound_list_1.mp3` came without a name; listen and rename.
